# Odin Recipes

A recipe website built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. This project demonstrates fundamental HTML and CSS skills including semantic markup, page linking, responsive layouts, and modern styling techniques.

## Overview

This is my first project in The Odin Project curriculum. It features a collection of three recipes with a homepage that links to each recipe page. Each recipe page includes a title, image, description, ingredients list, and step-by-step instructions.

## Live Demo

Open `index.html` in the browser to view the homepage.

## Recipes Included

- **Mini Bagel Pizza**
- **Perfect Hard Boiled Eggs**
- **Zucchini Bread Pancakes**

## Skills Demonstrated

- **HTML5 Semantic Markup** - Using `<header>`, `<main>`, `<nav>`, `<article>`, `<section>`, `<figure>`, and `<footer>` elements
- **CSS Layout** - Flexbox for responsive navigation and page structure
- **Typography** - Custom fonts from Google Fonts
- **Linking Pages** - Navigation between homepage and individual recipe pages
- **Responsive Design** - Viewport meta tag and flexible layouts
- **Image Handling** - Proper `<img>` attributes with `alt` text and figure captions
- **CSS Reset** - Box-sizing reset and margin/padding normalization

## What I Learned

- How to structure an HTML document with proper semantic elements
- Creating multi-page websites with internal navigation
- Using Flexbox for modern CSS layouts
- Writing clean, organized CSS with custom properties
- Linking external stylesheets and Google Fonts
- Building responsive designs that work across devices
